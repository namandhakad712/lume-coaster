# Tooling

## KiCAD MCP Server

Vendored copy of [mixelpixx/KiCAD-MCP-Server](https://github.com/mixelpixx/KiCAD-MCP-Server)
(MIT), `stable` branch, built locally.

Path: `tools/kicad-mcp/` — built artifact at `tools/kicad-mcp/dist/index.js`.

### What it does

Exposes KiCad's schematic, layout, and library APIs as MCP tools, so KiCad can
be driven from an agent rather than by hand. For this project it is the reason
schematic capture is scriptable at all — KiCad's own bundled Python has no
schematic-writing API, only `pcbnew`.

### How it was set up

1. Cloned `stable` branch.
2. `npm install` + `npm run build` → `dist/index.js`.
3. Python deps installed into `tools/kicad-mcp/pylibs/` with `pip --target`,
   because KiCad's own `site-packages` under `Program Files` is not writable.
4. One KiCad-specific gotcha: KiCad's bundled `sitecustomize.py` rebuilds
   `sys.path` from scratch at startup and **discards `PYTHONPATH`**. So the
   deps directory is registered via a `usercustomize.py` in KiCad's user
   site-packages (`Documents/KiCad/10.0/3rdparty/Python311/site-packages/`),
   which Python imports *after* `sitecustomize` runs. That file is generated by
   `scripts/setup-kicad-deps.py`.
5. Boot-verified end to end: `KiCAD MCP SERVER READY`, `pcbnew 10.0.7`.

### Two import-name mismatches to know about

| pip package | imports as |
|---|---|
| `kicad-skip` | `skip` |
| `kicad-python` | `kipy` |

The dist-info name and the import name disagree for both.

## Probes

One-off scripts in `tools/probes/` that established what the KiCad Python API
can and cannot do. Kept as evidence, not run regularly.

| Script | What it proved |
|---|---|
| `api-smoke.py` | `pcbnew` import, `NewBoard()`, `FootprintLoad`, `PCB_SHAPE` on Edge.Cuts |
| `api-roundtrip.py` | save + reload a `.kicad_pcb` without corruption |
| `find-sch.py` | KiCad's bundled Python has **no** schematic-writing API — hence the MCP server |
| `skip-probe.py` | the `skip` (kicad-skip) library can author `.kicad_sch` |
| `diag-python.py` | reproduced the `PYTHONPATH`-is-discarded behaviour |
